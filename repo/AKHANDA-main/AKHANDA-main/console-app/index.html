The refused entry

A REFUSED row is an operation that did not happen, recorded permanently. The witness was unreachable, so the tool blocked the run and wrote the refusal into the chain.

Ask a competing tool to show the log entry for an operation it declined to perform. There isn't one, a blocked attempt leaves no trace.

Reading custody tiers

WITNESS_COSIGNED a second key, on a physically separate machine, signed this entry.

SOFTWARE_KEY operator signature only, honest, and visibly weaker.

The ladder is SOFTWARE_KEY < PRESENCE_CONFIRMED < WITNESS_COSIGNED < FULL_CUSTODY. FULL_CUSTODY is never printed, it needs a presence device, which is designed and not shipped.

Media and custody

Stated limits, printed on the certificate itself

  • Integrity, not completeness. Establishes that recorded operations were not altered. Cannot establish that every operation was recorded.
  • Tail truncation. Removing the most recent entries leaves a shorter, self-consistent chain. Only the witness's own head record separates a truncated chain from a short one.
  • Partial dual signature. 1 of 2 performed entries carries both signatures.
  • No confirmed external anchor. Timestamps are the operator's own clock.
  • Blocked attempts. 1 operation was refused; reported separately, never folded into the result.
  • Form, not admissibility. Fields map to named clauses. Whether a court admits it is for the court.

Not tested, stated plainly
