# Locked Product Decisions

- DREX is fully offline.
- GitHub repository = implementation source.
- UI images = visual source of truth.
- Codex owns technical architecture and implementation decisions.
- Destroy Drive = information/assessment only; no physical destruction.
- Help = built-in offline Help Center; no external help website.
- Dashboard statistics = 4: Drives Wiped, Files/Folders Wiped, Files Recovered, Certificates.
- Wipe Drive = 7 methods; one selectable.
- Wipe File/Folder = 9 methods; one selectable.
- Recovery = 9 methods; one selectable.
- Filesystem Metadata Sanitization = one user-facing method.
- Recovery has live log + progress.
- Successful certificates require truthful successful/verified results.
- Installer = Inno Setup → `DREX-Setup.exe`.
