# Research basis

Primary references: NIST SP 800-88 Rev.2 (September 2025); IEEE 2883-2022; IEEE 2883.1-2025; current nvme-cli and platform-native storage tooling. NIST Rev.2 emphasizes enterprise sanitization programs and technology-appropriate qualified methods. IEEE 2883 specifies logical/physical sanitization methods and technology-specific guidance. This module never equates a generic host overwrite with Purge on flash storage.
