# Security model

- Sources are opened read-only.
- Offsets and lengths are range-checked before every read.
- Filesystem-declared sizes are bounded against source/partition size.
- Integer arithmetic uses checked helpers where practical.
- Recovery writes only to a user-selected destination.
- No shell commands or filesystem mounting are used by the core.
- Cancellation is cooperative and checked during long operations.
- JSON output is generated by the program, not a shell pipeline.

Before commercial release, add fuzzing for every parser and run the corpus under
ASan/UBSan and Windows verifier tooling.
