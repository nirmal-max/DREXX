# Commercial / forensic release gates

Before claiming courtroom-grade or law-enforcement-grade capability:
- complete NIST CFTT-style acquisition test plan
- independently validate write protection
- hardware write-blocker adapter matrix
- Windows/Linux/macOS device acquisition
- E01/AFF4/raw image adapters as appropriate
- bad-sector acquisition integration with Module 8
- signed manifests and event records
- secure time source / clock-drift recording
- role-based case access
- immutable case storage
- independent SHA-256 verifier
- reproducibility tests
- legal/jurisdiction review
- external forensic practitioner review
