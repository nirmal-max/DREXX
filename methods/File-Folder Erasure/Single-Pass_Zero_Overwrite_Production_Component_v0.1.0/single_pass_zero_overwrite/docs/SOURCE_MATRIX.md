# Research / software matrix

| Software / standard | Use in research | License / status | Bundled? |
|---|---|---|---|
| NIST SP 800-88 Rev. 2 | Policy and terminology | Public standard | No |
| Nwipe | Zero fill, I/O, verification, media caveats | GPL | No |
| Microsoft SDelete | Windows secure-delete behavior | Microsoft Sysinternals | No |
| Eraser | Open-source overwrite architecture | GPLv3 | No |
| SecureWipe | NIST/ANSSI workflow and test-disk architecture | GPLv3 | No |
| secure_delete | Cross-platform file/folder workflow | MIT | No |
| The Devourer | Windows chunked overwrite/CSPRNG behavior | Open source | No |
| GNU shred | POSIX overwrite reference | GPL | No |

## Why no third-party source is copied

The deliverable is intended to be independently commercializable. It therefore contains
only the new implementation and documentation. Third-party implementations should be
integrated only after their exact licenses and obligations have been reviewed.
